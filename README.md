# Terraform Lesson

## What is Terraform?
Terraform is a tool that uses configuration files to provision and manage infrastructure.

## What is infrastructure?
Infrastructure is the computing resources and supporting setup an application needs to run.

## What is a server?
A server is a computer that handles requests from other computers or applications.

## What is a virtual machine (VM)?
A virtual machine is a computer created in software that runs on a physical computer and behaves like a separate computer.
